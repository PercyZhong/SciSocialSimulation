# SciMirror v0.1 实验协议（2026-09-09）

## 已冻结的研究问题
在本模拟器的明确假设下，改变科研奖励权重和合作候选集合，是否改变科研提案文本差异、跨领域合作比例和团队规模？这是模拟内部机制实验。需要真实文献和独立评审才能进一步讨论科研 Idea 的质量；不能从本版本得出现实科研政策的因果结论。

## 第一版范围
20个合成科学家，三个领域 agents / learning / science，数量7/7/6。每人拥有私有偏好（新颖性、声誉、风险、合作）、压力、资源、记忆、信任；公开字段仅含身份、领域、声誉和可合作状态。职业阶段、完整知识图谱、机构智能体、真实实验执行、论文发表及多项目并行不在v0.1实现范围内。

原始大方案的第一版收敛为：每人每周期最多参加一个项目，每队1—2人，成员角色按周期交替。未参与合作者独立提交。每周期会重新组队；成员草案作为贡献被保留但不与团队最终卡重复计数。这是有意的实验约束，后续可扩展容量。

默认动态价值关闭，避免把价值漂移同时作为未经校准的假设和待验证结论。压力、声誉和信任按公开的有界规则更新，不能称为对人类心理的实际测量。团队选择和接受用结构化规则；LLM生成两个候选提案，Python效用函数抽样选择；LLM进行修订。这里实现的是混合型LLM-Agent，并非每个动作都由模型自主选择。

## 实验条件
| 因子 | 条件 | 具体操作化 |
|---|---|---|
| 奖励 | balanced | 新颖性代理/熟悉度代理权重0.5/0.5 |
| 奖励 | novelty | 权重1/0 |
| 奖励 | recognition | 权重0/1 |
| 合作 | closed | 只能邀请同领域候选人 |
| 合作 | open | 可以邀请所有领域候选人 |

recognition是与历史文本的词集合相似度代理，不是引用量、可发表性或实际声誉预测。该代理与新颖性代理互为补数，仅用作透明的制度操作化；两者之间的负相关不能作为实验证据。closed改变了候选人数和学科构成两个因素，因此网络效应是此组合干预的总效应，不能直接归因于学科多样性。后续应固定候选数并加入匹配对照。

## 时间协议
一个tick是一次全体代理决策阶段，不对应现实的一天/一周。

| tick % 6 | 阶段 | 实现 |
|---:|---|---|
| 0 | 阅读/提案 | 检索3篇；每人生成2个候选；Python效用选择一个 |
| 1 | 邀请 | 10位轮换负责人各最多邀请1位伙伴 |
| 2 | 接受/拒绝 | 受邀者在同一快照上选择最多1个邀请 |
| 3 | 分享 | 团队内共享当期草案 |
| 4 | 批评/修订 | 每个负责人修订1张卡；有伙伴时加入共享卡 |
| 5 | 评价/反馈 | 去重计数最终提案，更新声誉、压力、信任、记忆 |

30 ticks = 5周期。0—5 tick采用balanced/open共同前缀。tick=6保存检查点，并分叉到6个条件；之后4周期为干预期。汇总仅统计干预后的输出，避免共同前缀稀释效应。

## 决策函数
候选c的主观特征由模型生成，均位于[0,1]：n=预期新颖性，f=预期可行性，r=预期认可。

U_i(c) = v_n*n + v_r*r - v_risk*(1-f) + 0.5*(policy_n*n + policy_r*r)

对两个效用以temperature=0.2进行softmax抽样。这些是主观估计，不能当作外部评估结果。邀请考虑已有信任与领域互补；接受概率=0.3+0.65*合作偏好，并受资源及单项目约束。资源以整数单位计数，范围[0,100]，每tick恢复8；提案成本20、加入成本15、修订成员成本10。

## 可见性及事件一致性
决策只读取self私有状态和其他人的公开投影，不能查询全局私有状态。分享卡在队内显式可见。实验者日志可以包含私有状态，不应作为其他Agent提示词。

每tick在copy-on-write状态上工作，模型或校验失败不改变输入World。成功后追加领域事件及world.snapshot提交记录。checkpoint.json原子写入。文件中断时严格重放会拒绝损坏行；没有自动修复，不可自行删行伪装成功。

该MVP使用“领域事件审计 + 每tick完整快照恢复”，尚不是为每种事件实现独立reducer的完整Event Sourcing。重放以snapshot为恢复来源，对完整日志做SHA256链接验证。上一轮方案中的事件parent链只能表示程序依赖，不能证明社会科学因果关系，本版不生成虚假的因果边。接收方自主选择先解决多邀请冲突，再检查容量。

## 随机性和反事实
随机数以(seed,tick,agent,用途)散列成独立流，不把branch或policy放进键；各分支中同一语义机会使用共同随机数，避免一个分支多一个动作就打乱所有后续抽样。

所有分支在施加policy/network前的完整state_hash相同。干预后动作/检索/模型输入本来就可以不同，不应强行保持检索结果一致，否则会冻结真实的行为中介过程。

远程模型即使temperature=0也不保证完全确定。请求和响应缓存以endpoint、model、参数、完整输入和语义键为索引。相同请求可重用，改变实验世界seed不会误共享随机生成。日志重放不调用模型。cache_only=true要求所有请求已缓存；缺失时立即失败。恢复实验的方法是保留cache，以同一配置启动新的输出目录；已有完整请求会命中缓存。本版不提供从任意坏文件自动断点续写。

## 数据与泄漏边界
内置90条文献全是明确标记synthetic=true的英文工程夹具，没有真实作者，也没有虚构成真实论文的DOI。用于验证协议、指标和文件输出，不可作为论文实验数据。

真实输入：UTF-8 JSONL，每行至少有id/title/abstract/year/field/synthetic；synthetic=false必须来自用户核验的真实文献。year>=cutoff_year一律排除。默认代理画像仍是合成的，因此即使输入真实文献，也不能声称真实科学家数字孪生已经校准。

本版检索仅是英文token Jaccard，不是嵌入RAG。中文摘要不适合当前tokenizer。时间过滤只控制可检索内容，无法排除LLM预训练已见过未来论文；模型知识泄漏须在正式研究中单独检验。

## 输出与评价
- summary.csv：每个世界seed、每个条件的干预期指标。
- trajectories.csv：每周期累计干预期指标。
- paired_effects.csv：同网络内相对balanced的配对效应及bootstrap区间。
- blind_review.csv：只含匿名卡ID、文本、参考文献ID和空评分列。
- review_key_private.csv：匿名ID到条件映射，不给评审者。
- REPORT.md：结果表与解释边界。
- manifest.json：Python/平台/配置/源码/语料散列、模式和模型名。
- usage.json：真实HTTP尝试数、缓存命中和服务端报告token。
- seed_*/prefix/fork.json：分支共同检查点。
- seed_*/*/events.jsonl：审计事件与状态快照。

novelty_proxy=1-max历史文献Jaccard相似度，可能奖励改写、噪声和无意义文本；text_diversity=最终卡两两平均词集合距离；owner_field_entropy是产出者学科熵，不是研究主题熵；cross_field_rate是跨领域最终提案比例；mean_team_size是最终提案平均贡献者数。

每个seed的完整社会是统计独立单位，不把20个Agent、单篇Idea或一个世界的多tick视为独立样本。配对bootstrap在世界层重采样2000次；一对世界不输出区间。默认3seed及LLM试跑1seed只用于探索。正式配置20seed也不是功效保证；应先估计方差，再根据最小关注效应做功效分析。区间是逐指标、未做多重比较调整的探索性区间。

建议人工评价：至少两位对条件盲法的领域评审，分别评新颖性与可行性1—5分，写理由；独立评价后再讨论分歧。不要让生成器按其自己的奖励函数给自己做最终质量判定。

## 调用规模
每周期20次提案调用+10次修订调用=30次逻辑调用。其余阶段无需LLM。
- mock：20Agent/30tick/3seed/6条件，2250次逻辑生成，全本地，无网络调用。
- llm_pilot：20Agent/12tick/1seed/6条件，210次未缓存逻辑调用。
- llm_research：20Agent/30tick/20seed/6条件，15000次未缓存逻辑调用。

max_calls按整个执行的HTTP尝试累计，包含重试；不等于token预算。max_tokens只限制每次输出，请求输入另计。重试最多3次，配置预算可能先耗尽，此时保存失败状态并退出。不要自动启动正式批量实验；先用doctor --probe测1个请求、确认模型格式，再查看estimate。
